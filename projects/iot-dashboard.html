FEATURED PROJECT

Smart IoT Dashboard

A Firebase-powered remote monitoring and control system built using ESP32 and Android.

Project Overview

This project allows users to remotely monitor sensors, control electrical devices and synchronize data using Firebase Realtime Database.

Technologies Used

  • ESP32
  • Firebase Realtime Database
  • Android Studio (Java)
  • WiFi Communication

The Problem

Traditional electrical systems require someone to be physically present to monitor equipment and operate switches. This becomes inefficient for remote locations.

The Solution

A cloud-connected ESP32 communicates with Firebase, allowing an Android application to monitor sensors and control devices from anywhere with internet access.
