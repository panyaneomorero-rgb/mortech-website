Smart Intruder Alert

An intelligent IoT security system designed to detect movement and provide real-time remote intrusion alerts.

Project Overview

Smart Intruder Alert is an IoT-based security system built around an ESP32 microcontroller and PIR motion sensor.

When movement is detected, the ESP32 sends information to Firebase Realtime Database, allowing the user to monitor the security system remotely.

Technologies Used

ESP32 PIR Sensor Firebase Android Wi-Fi IoT

Key Features

📡 Motion Detection

PIR sensor detects movement and sends the event to the ESP32.

☁️ Firebase

Firebase Realtime Database provides communication between the IoT device and the application.

📱 Remote Alerts

The Android application allows the user to receive intrusion information remotely.
